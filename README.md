# Web Hotel Paraíso

## 📖 Descripción

▪ Hotel Paraíso es una página web simulando un hotel vacacional lacalizado en la isla de Lanzarote(España). 

> [!WARNING]  
> *No es una web real*. Realizado sin JS, compuesto unicamente por HTML y CSS.
